# Technical Hub × NCET — Claude Success Story

A single-page website showcasing how **Technical Hub** is building a future-ready, AI-skilled
institution at **Nagarjuna College of Engineering and Technology (NCET)** through campus-wide
AI awareness, dedicated AI Skill Enrichment Labs, Claude-aligned curriculum integration, and
the deployment of Claude-certified architects.

## Tech stack

Built with the same front-end stack the NCET site (ncet.co.in) renders:

- **HTML5**
- **Bootstrap 5** — responsive grid & components
- **jQuery** — navbar behaviour, scroll-spy, animated counters
- **AOS** — scroll animations
- **Google Fonts** (Poppins + Inter) and **Bootstrap Icons**

All imagery is sourced from the official project documentation and lives in [`/images`](images/).

## Run it

No build step required — just open the file in a browser:

```
index.html
```
